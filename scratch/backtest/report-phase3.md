## 4. 公募割れ確率（numpy ロジスティック回帰、L2 λ=1、ニュートン法、特徴量は各 points を学習期間で標準化）
| 特徴量セット | 検証2024〜 AUC / ブライア(基準0.1842) | 検証2023（学習〜2022） AUC / ブライア(基準0.2129) |
|---|---|---|
| 日経MA地合い | 0.734 / 0.1604 | 0.692 / 0.2089 |
| 直近IPO地合い（採用） | 0.750 / 0.1528 | 0.689 / 0.1956 |
| 両方（参考） | 0.763 / 0.1476 | 0.711 / 0.1981 |

λ=0.1 と 10 でも AUC は 0.749。採用は日経MA版と直近IPO版の2択で、AUC 合計とブライアの両方で上回った直近IPO版にした。「両方」の方が数値は良いが、アプリの地合いは合成判定か手動設定で、学習に使った「日経25日MA±2%」を再現できないため入れていない。
係数（標準化後）: 切片 −2.244、吸収 −0.761、直近IPO −0.638、仮条件 −0.463、OR −0.376、売出比率 −0.170、同週 −0.132、VC×ロック −0.112、主幹事 +0.238、幹事団社数 +0.296。
キャリブレーション（検証2024〜、10分位×18件、予測→実績）: 2.7→11.1 / 6.7→11.1 / 9.7→5.6 / 13.0→16.7 / 17.4→5.6 / 22.8→11.1 / 28.1→27.8 / 35.5→38.9 / 44.0→50.0 / 66.7→55.6。5分位では 5→11 / 11→11 / 20→8 / 32→33 / 55→53。
「概ね単調」の判定: 10分位の番号と実績率の Spearman ≥ 0.6、かつ上位3分位の実績平均 > 下位3分位の実績平均。最初は「10pt以上の逆転が2回以内」で試したが、1分位18件（1件で5.6pt動く）だとノイズだけで外れるため差し替えた（変更したことをここに残す）。結果は +0.78 で採用。
補助の検証（学習〜2022 → 2023）: AUC 0.689。10分位の Spearman +0.54 で基準未達。上位20%の識別は効くが、下位〜中位は区別がつかない。2023年の公募割れ率は 27.1% で、学習期間の 14.7% より高い。

## 6. 限界
1. 低い確率は実際より低めに出る。最下位10分位は予測2.7%に対し実績11.1%。学習期間の公募割れ率 16.1% より検証期間の 23.3% が高く、水準がずれている
2. BB期間中は直近IPOの一部しか分からない。検証だけ「14日前までの直近5件」に差し替えると AUC 0.734、学習・検証とも14日前版だと 0.715（どちらも基準 0.65 は超える）
3. 主幹事実績の係数が逆向き（+0.238）で、単独でも −0.013。スコアの重みは範囲外として据え置いた。次の見直し候補
4. VC×ロックアップは全期間でほぼ無相関（−0.004、5/12年）。重みは据え置き。次の見直し候補
5. 幹事団社数の正の係数は、他項目と一緒に入れたときの残差。解釈しない
6. 2015〜2023 と 2024〜 はデータの取得経路が違い、VC・ロックアップの取り方が完全には揃わない
7. 同週件数は手元リストで数えている（TOKYO PRO 等は含まない）
8. 2026年は29件で、年別の値がぶれやすい
9. アプリの主幹事実績（page.tsx）は直近3年固定だが、学習は全期間の上場前実績で、定義が少し違う
10. 実績分布の機械的集計であり、将来の結果を保証しない
