# Phase 3 — セカンダリーのイベント前後リターン検証

- 作成: 2026-09-25 / スクリプト `event_backtest.py` / 明細 `data/out/event_samples.csv` / 集計 `data/out/event_summary.json`
- アプリ用の小さい集計: `public/data/event-stats.json`（種別ごとの sampleCount・meanBefore20・meanAfter5・meanAfter20・medianAfter20・winRateAfter20・years）
- 価格データ: `fetch_prices.py --add-missing --refresh` で 2026-09-25 まで更新（yfinance 日足、分割補正は Close × split_factor で上場時スケールに換算）

## 1. データと方法

| 項目 | 内容 |
|---|---|
| 対象銘柄 | ipo_list.csv 188 銘柄（アプリの上場済 181 銘柄のうち未収録 19 銘柄を追記）。価格CSVあり 179 銘柄 |
| 取得失敗 | yfinance が空を返した 14 銘柄（176A, 202A, 231A, 242A, 259A, 260A, 5241, 7118, 7790, 9388, 353A, 391A, 418A, 275A）。うち 231A/242A/5241/9388 は以前取得した CSV（2024-12〜2025-06 まで）を残して使用。残り 10 銘柄は価格なしで対象外 |
| ロックアップ解除日 | 上場日 + lockup_days（暦日。fundamentals.csv、欠損は ipos.enriched.json）以降の最初の営業日を T |
| 1.5倍解除到達日 | lockup_has_15x の銘柄で、終値（分割補正後）が公開価格×1.5 を初めて上回った日を T |
| 初回決算 | ipos.auto/base.json の firstEarningsDate が上場日より後かつ価格データ内のもの |
| リターン | before20 = T の終値 / T−20営業日の終値 − 1、after5/after20 = T+5/T+20 営業日の終値 / T の終値 − 1。窓が足りない指標は欠損 |
| ベンチマーク | 同じ暦日区間の「他の全IPO（上場から20営業日経過済み）」の等加重平均。超過 = 個別 − ベンチマーク |
| 勝率 | リターンがプラスだった割合 |

### 2-3. 1.5倍解除到達の内訳

- 27 件中 15 件は上場から 5 営業日以内に到達（初値形成直後の急騰で到達）。そのため before20 は 10 件しか計算できない。
- 上場5営業日以内に到達（after20 あり 13 件）: 中央値 約 −20.6%、勝率 5/13。
- 6営業日目以降に到達（12 件）: 中央値 約 −6.5%、勝率 3/12。

## 3. 使える示唆（弱い・参考情報として）

- **1.5倍解除到達後の20営業日は、中央値ではマイナス側に寄っていた**（中央値 −6.8%、勝率 32%）。到達時期で分けてもどちらも中央値はマイナス。ただし 25 件と少なく、年によって符号が逆転する（2025 年は中央値 +9.6%）。「到達後は需給が重くなりやすい傾向が過去にあった」という程度の注意喚起には使える。
- **90日ロックアップの解除後は、180日より弱い実績だった**（after20 中央値 −11.8% vs +1.6%）。ただし 90 日は 17 件で、2024 年の 11 件に偏る。ロックアップ日数を区別して見る価値があることは示唆する。
- **ロックアップ解除日の前20営業日は、同期間の他IPOより中央値で約 −3% 劣後**（勝率 37%）。「解除日が近い銘柄は相対的に弱含みやすかった」という傾向は、件数（142件）がある程度あり比較的安定。

## 4. 使えない示唆（言えないこと）

- ロックアップ解除 **後** の値動き（全体）は、平均 +4.4% / 中央値 +0.2% / 勝率 50% で **ほぼ五分**。平均は少数の大幅上昇銘柄（最大 +475%）に引っ張られており、「解除後に上がる/下がる」とは言えない。
- 初回決算は **3 件のみ**（firstEarningsDate を持つ銘柄が少ない）で、何も言えない。96ut 等から過去の初回決算日を補完するまで保留。
- ベンチマーク超過の平均がプラスでも中央値はマイナス、という指標が多く、分布の歪みが大きい。平均値だけを表示に使うのは避ける（アプリは中央値と勝率を主に表示）。
- 期間は 2024〜2026 年の約2.5年分のみ。IPO 地合いの局面が1〜2回しか含まれず、年別の符号反転も多い。ルール化（機械的な売買判断）に使える強さはない。

## 5. 限界

- **生存者バイアス**: yfinance で取得できない銘柄（上場廃止・TOB・コード変更等の可能性）14 銘柄は大半が対象外。上場廃止銘柄の下落が集計から漏れている可能性がある。
- **ロックアップ解除日の近似**: 目論見書の「上場日から起算して N 日目まで」の起算方法・営業日/暦日の差を無視し、上場日 + N 暦日以降の最初の営業日で近似。1.5倍解除も「終値ベース」で判定しており、実際の解除条件（取引所の終値か、ザラ場か、何日連続か）は銘柄ごとに異なる。
- **ロックアップの対象株数**を考慮していない（解除される株数が少ない銘柄も同列）。
- **終値基準**: イベント日 T の終値を起点にしているため、T 当日の反応（寄り付きからの動き）は after 側に入らず before20 側に入る。
- **ベンチマーク**は IPO 銘柄同士の等加重平均で、小型株指数や TOPIX ではない。
- 1.5 倍到達を「解除が発生した」とみなしているが、実際にロック株が売られたかは分からない。
- 取引コスト・流動性（出来高が少ない日の約定可能性）は考慮していない。
